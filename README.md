# AUREL by Dhanush

AUREL is a fictional premium watch brand website created by **Doddi Dhanush Kumar Reddy** for CSE2313 Web Development at Sir Padampat Singhania University, Udaipur. All product imagery, specifications, and INR prices are illustrative. The timepieces are unavailable for purchase.

[View the live website](https://doddidhanushkumarreddy.github.io/aurel/)

## Technology

HTML, CSS, and vanilla JavaScript. The site uses responsive layouts and serves its image and video assets locally.

## Collection

| Category | Timepieces |
| --- | --- |
| Dress | Sovereign, Heritage, Regent |
| Everyday | Meridian, Solstice |
| Sport | Velocity |

## Features

- Filter the collection and open product details with illustrative INR pricing.
- Browse six views per watch with thumbnails, previous and next controls, arrow keys, and touch swipes. Select an image to open the lightbox.
- Watch the embedded English demo with on-screen captions and background music.
- Read the brand story and developer profile.
- Prepare an email enquiry. The contact form opens a draft in the visitor's configured email app. It sends no messages and stores no form submissions.

## Run locally

Download and extract the repository ZIP, or clone the repository. Open `index.html` in a current browser and keep the `assets` folder beside it. The core site works offline. Sending an enquiry requires a configured email app and internet access.
